# nurie
線画に色を載せる塗り絵用の Web アプリ。

画像を読み込むと黒い線だけを抽出し、線で囲まれた場所を、自分で決めた RGB の色で塗れる。

## 使い方

```
npm install
npm run dev
```

公開先: https://tyaki-geo.github.io/nurie/

1. 画像を選ぶ（ドラッグ＆ドロップ、貼り付けも可）
2. 右のパネルの「線の抽出」を選ぶ。写真なら「自動」（既定）、スキャンやデジタルの線画なら「単純」。「しきい値」で、拾う線の濃さを調整する
3. 右の「色」パネルで色を決める。パレット（24色）か、スペクトルのカラーピッカーから選び、R・G・B・A（透明度）のスライダーと数値で細かく調整する。RGB の値を出すのはこのパネルだけで、各行の右に R+G+B に対する割合（A は不透明度の%）が出る。最近使った色にも戻れる
4. 上のツールバーでツールを選んで塗る
   - **塗りつぶし**: 線で囲まれた領域をクリックすると、すぐ塗る
   - **複数選択**: 領域をクリックで選択・解除し（斜線で示す）、「選択を塗る」で選んだ全部を同じ色にまとめて塗る。右上の「番号を表示」で領域の番号が見え、`1, 3, 5-8` のように番号を入力して選ぶこともできる
   - **線に沿って塗る**: ドラッグでなぞって塗る。**線からはみ出して塗れる**。太さ（1〜60px）はカーソルの円で確かめながら調整できる。下の線の扱いを選べる
     - **残す**: 線の下に色を敷く。線は黒のまま残る
     - **消す**: なぞった所の線を消して、色で塗りつぶす
     - **線の色を変える**: なぞった所の線そのものの色を変える（線の上だけ。はみ出さない）
5. 上のバーの「元に戻す」「やり直し」（Ctrl+Z / Ctrl+Shift+Z）、「PNG で保存」（透明度つき）。右下の「線の色・消した線を元に戻す」「色をすべて消す」

## 仕組みと制限

- **線の抽出は2通り**
  - **自動（写真向け・既定）**: 紙を撮った写真のように、影・机・他の物が映っていても、細い黒い線だけを取り出す。まわりの明るさ（線を除いた背景）に対する比で測るので、影の濃さに影響されない。線より広い暗い部分（影・机）は線にならない。紙は色（彩度の低さ）で探し、紙の部分だけを切り出す（「紙の部分だけを切り出す」で切り替え。紙の外の線は無視する）。「線の太さ」は、線として拾う太さの上限の目安（px）で、読み込み時に画像の大きさから決まる
  - **単純**: 画素の黒さをそのまま使う。スキャンやデジタルの線画向けで、太い黒ベタも黒として扱う
  - 設定を変えると線の抽出をやり直すので、塗った色は消える（塗った内容があるときは確認する）
- 黒さは画素の最も明るいチャンネルで測る。色のついた線（赤など）は「黒」ではないので線にならず、塗る場所として扱う。透明は白として扱う
- **領域の番号**: 線でない画素の、上下左右につながる範囲を1つの領域とし、画面の左上から順に 1, 2, 3… と番号をつける（`src/lib/regions.ts`。同じ画像・同じしきい値なら番号は同じ）。しきい値を変えると領域の切れ目が変わるので、番号と選択は作り直される（塗った色は画素ごとに残る）。すべてブラウザの中で計算し、サーバは使わない
- 線が途切れていると、隣の領域とつながって1つの領域になり、外にはみ出す。そのときは線のしきい値を下げる（薄い線まで拾う）
- **透明度**: 塗った色は RGBA で持つ。半透明に塗った所は下の市松模様が透け、PNG 保存でも透明度が残る。A = 0 で透明にもできる。同じ領域を塗り直すと、前の色に重ねずに置き換わる。色を塗っていない領域は不透明な白
- 線の縁のなめらかさを残すため、線は黒さに応じて領域の色に重ねている。線の色は領域の色とは別の層（初期は不透明な黒）
- 長辺が 2048px を超える画像は縮小して読み込む
- 画像はブラウザの中だけで処理し、外には送らない

## 開発

- 画像処理は `src/lib/`（DOM に依存しない。`photo.ts` 写真からの線の抽出と紙の検出、`lineart.ts` 線の濃さ・色・合成、`regions.ts` 領域の番号、`brush.ts` ブラシの範囲）。テストは `tests/`
- 運用（ブランチ・PR・CI）は [CLAUDE.md](CLAUDE.md)、テンプレート由来の設定の反映手順は [docs/template-setup.md](docs/template-setup.md)
