# nurie
線画に色を載せる塗り絵用の Web アプリ。

画像を読み込むと黒い線だけを抽出し、線で囲まれた場所を、自分で決めた RGB の色で塗れる。

## 使い方

```
npm install
npm run dev
```

1. 画像を選ぶ（ドラッグ＆ドロップ、貼り付けも可）
2. 「線の抽出」のスライダーで、拾う線の濃さを調整する
3. R・G・B（または 16進数、カラーピッカー）で色を決める
4. 塗りたい場所をクリックする。「元に戻す」「やり直し」（Ctrl+Z / Ctrl+Shift+Z）、「PNG で保存」ができる

## 仕組みと制限

- 黒さは画素の最も明るいチャンネルで測る。色のついた線（赤など）は「黒」ではないので線にならず、塗る場所として扱う。透明は白として扱う
- 塗る範囲は、線で囲まれた領域（上下左右につながる、線でない画素）。線が途切れていると外にはみ出す。そのときは線のしきい値を下げる（薄い線まで拾う）
- 線の縁のなめらかさを残すため、線は黒さに応じて塗った色に重ねている
- 長辺が 2048px を超える画像は縮小して読み込む
- 画像はブラウザの中だけで処理し、外には送らない
